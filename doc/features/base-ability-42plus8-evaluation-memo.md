# 基础能力测评 42+8 方案评估备忘录

状态：讨论备忘录，待产品与专业评审确认  
日期：2026-07-15  
适用范围：`BASE_ABILITY` 基础能力测评，不适用于 `JOB_SKILL_ASSESSMENT` 专业岗位示范测评。

> 当前执行入口已收口到 `doc/features/base-ability-current-contracts.md` 和 `doc/features/base-ability-42plus8-activation-gate-v1.json`。本备忘录只保留分数解释、试测定位和专业评审风险，不授予激活权限。

## 结论

现行“42 道线上题 + 8 道线下题”的方案可以组成一份固定试测卷，也适合用于教学诊断和训练建议。它目前不具备作为已验证标准化量表、诊断工具或单独用于就业安置判断的证据基础。

题量不是科学性的充分条件。分数解释需要先明确要测什么、每个构念的权重为何如此分配，以及测评结果和后续教学或实操表现之间是否存在稳定关系。教育与心理测验的通行标准也要求，分数解释应由具体用途对应的内容、反应过程、内部结构、外部关系和使用后果等证据支持，而不是把题目数量直接等同于效度。[Standards for Educational and Psychological Testing](https://www.testingstandards.net/uploads/7/6/6/4/76643089/standards_2014edition.pdf) [APA Guidelines for Psychological Assessment and Evaluation](https://www.apa.org/about/policy/guidelines-psychological-assessment-evaluation.pdf)

当前策略中的 `pilot_mode: true` 与这一定位一致。

## 已核实的题库供给

内容包约定导入 96 条 `BASE_ABILITY` 源题。导入文件的结构如下：

| 模块 | 线上计分候选 | 线下实物候选 | 观察项 |
|---|---:|---:|---:|
| 精细动作 `FINE_MOTOR` | 9 | 7 | 0 |
| 认知理解 `COGNITION` | 20 | 0 | 0 |
| 规则执行 `RULE_EXECUTION` | 16 | 0 | 0 |
| 情绪调节 `EMOTION_REGULATION` | 13 | 0 | 1 |
| 基础社交 `BASIC_SOCIAL` | 14 | 0 | 0 |
| 安全操作 `SAFETY_OPERATION` | 15 | 1 | 0 |
| 合计 | 87 | 8 | 1 |

因此，按每个模块 7 道线上题的规则，可以选出 42 道线上题；8 道线下题也恰好够用。线下题没有替换余量，精细动作模块线上候选也只多出 2 道。出现资源缺失、感官避让或专业审核未通过时，系统应按 PRD 进入“题库不足”或“感官屏蔽后题目不足”分支，而不能静默减少题量。

源题目前仍是候选内容：导入 SQL 中的题目状态均为 `DRAFT`，评分规则为 `NO_SCORE`。本机运行库在本次核对时也没有 `BASE_ABILITY` 题目。上述状态说明 96 条是内容合同和候选池，不等于已经可以施测的 96 条正式题。

## 分数解释的主要风险

线上部分按六模块各 7 题、每题 0 或 2 分计算，每个模块为 14 分。8 道线下题按每题 0、1、2 分计入总分，而现有候选题中 7 道属于精细动作、1 道属于安全操作。若直接合计为 100 分，总分的最大分值构成为：

| 模块 | 线上分值 | 线下分值 | 总分中的最大分值 |
|---|---:|---:|---:|
| 精细动作 | 14 | 14 | 28 |
| 安全操作 | 14 | 2 | 16 |
| 认知理解 | 14 | 0 | 14 |
| 规则执行 | 14 | 0 | 14 |
| 情绪调节 | 14 | 0 | 14 |
| 基础社交 | 14 | 0 | 14 |

这套权重可以用于“超市理货员的基础准备度”判断，前提是产品与专业人员明确认可精细动作和安全操作应获得更高权重，并在报告中如实说明。它不支持把总分表述为六项能力等权的通用基础能力分数。

重复施测也会受到题库规模限制。线下题没有平行题，重复使用同一任务会带来熟悉效应。当前 MVP 不应声称实现了随机组卷、平行卷或稳定的复测比较。

## 建议的决策

### 1. 先固定试测定位

在完成内容审核和课堂试测前，产品名称和报告措辞统一使用“基础能力教学诊断试测”。结果用于制定训练重点、记录变化和安排教师支持，不单独产生诊断结论或就业安置结论。

### 2. 处理线下题的权重问题

需要在以下两条路径中选择一条，并将结果写入权威 PRD 和评分策略版本：

- 将总分定义为“理货岗位基础准备度指数”，保留精细动作 28 分、安全操作 16 分的权重，并写明岗位关键性依据。
- 将线上六模块分数作为基础能力主画像，线下 8 题改为独立的直接表现画像或重建线下题池，使线下覆盖与权重能支持预期的六模块解释。

在未作出该决定前，不应把 100 分总分解释成六项基础能力的综合等权分数。

### 3. 将固定卷建设为可施测内容

对选入固定卷的 50 道计分题逐题完成答案键、线上 renderer、素材资源、感官标签、线下三档行为锚点和专业审核。所有题目通过门禁后再从 `DRAFT` 转为 `ACTIVE`。线下题还应补齐复合能力标签和标准教具条件，以便教师按同一条件施测和评分。

### 4. 用课堂试测收集证据

试测阶段至少持续记录以下信息：题目完成时间、跳题和情绪中断、感官筛除或替代发生率、线下评分的教师间一致性、复测时的熟悉效应，以及分数与后续训练完成度、任务实操评分之间的关系。完成一轮有记录的试测后，再决定阈值、模块权重、报告用语和是否需要平行题。

## [!] 需要先收口的合同与工具差异

当前 PRD 的基础能力策略允许 `TRUE_FALSE`、`SINGLE_CHOICE`、`DRAG`、`SOFTWARE_TASK` 四类线上题。2026-07-22 已将题库上线门禁脚本同步为同一口径：`SOFTWARE_TASK` 计入线上题，并显式限制 `bank_domain = 'BASE_ABILITY'`。

这只修正了机器统计口径，不代表基础能力题库已经可激活。当前 `base-ability-42plus8-activation-gate-v1.json` 仍显示 96 条均为 `DRAFT` / `NO_SCORE`，素材、renderer、线下教具、评分锚点、专业审核和课堂试测证据均未闭合。

在开放基础能力测评前，应修正该脚本并以同步后的运行库重新生成门禁报告。
