# 首批 6 个出图试跑验收清单

**对应批次**：`doc/features/question-bank-image-batch-pilot-v001.json`  
**目的**：先验证风格方向、场景稳定性、错误态 edit 链路、拖拽底图可用性、拖拽物素材可读性  
**本清单用途**：每个 job 出图后，对照逐项打勾；通过后再扩第二批

---

## 1. 验收原则

这 6 个 job 不是看「好不好看」，而是看「能不能稳定作为测评资产继续批量扩展」。

通过的最低标准：

1. 风格统一：都像同一套职业测评素材，不像 6 个不同项目。
2. 场景稳定：能作为后续 `correct / wrong` 或更多题目的母版继续复用。
3. 动作清楚：正确态和错误态一眼能区分，不靠文字解释。
4. 交互可用：拖拽底图和拖拽物缩小后仍能看清。
5. 无多余噪音：不能出现广告感、海报感、乱码文字、乱入人物、奇怪道具。
6. 人物与环境符合中国大陆学校使用语境：人物应为东亚面孔，环境不能明显偏海外卖场。

---

## 2. 整体通过条件

### 必须全部满足

- 所有场景图都保持写实、冷静、训练素材风格。
- 人物服装基本一致：浅灰上衣、深色围裙、深色裤子、防滑鞋。
- 人物默认应为东亚面孔，气质贴近中国大陆学校实训场景。
- 室内光线统一偏中性，不能一张暖黄、一张冷蓝、一张电影打光。
- 货架、桌面、通道、安全角等环境不能出现强烈风格漂移。
- 不能出现不可控品牌 Logo、乱码标签、夸张商超广告牌。
- 大量重复货架商品不能出现明显无意义乱码；若难以稳定控字，应优先采用无文字 / 低文字包装。
- 不能出现多余人物抢画面。
- 不能出现明显海外零售卖场感、明显非中文语境的环境暗示或明显非亚裔人物主角。

### 任一出现则判定为不通过

- 明显 AI 异常：手指错位、商品变形、货架透视乱、人物肢体不自然。
- 明显非亚裔人物主角，或人物面孔明显不符合中国大陆学校使用场景。
- 错误态与正确态差异不明确，或者直接改坏了整个场景。
- 拖拽底图本身信息太杂，后续叠 UI 会脏。
- 拖拽物过小、反光过强、轮廓不清，缩略后不可辨认。
- 风格偏广告拍摄、商业海报、宣传图，而不是训练评估素材。
- 环境明显像海外大卖场或西式商业广告片场。
- 货架大量商品包装出现明显无意义乱码，影响真实感和测评可用性。

## 3. 单 job 验收清单

### 3.1 `JDG-MS02-standard-shelf-master-v001`

用途：货架母版。

通过标准：

- 货架结构清楚，层数、格位、价签轨道自然。
- 机位稳定，正面偏平视，透视不过分夸张。
- 环境干净但不空，能看出是超市训练区。
- 后续可在同一场景上继续做摆放正确/错误、价签匹配、同类归位等题。

失败信号：

- 货架像商拍样板间，不像训练现场。
- 商品、背景、补货车过于抢眼，主次失衡。
- 货架角度太斜，不适合后续批量 edit。

### 3.2 `JDG-MS02-facing-correct-v001`

用途：货架正面朝外正确态。

通过标准：

- 商品正面朝外明显。
- 排列整齐、间距均匀、没有歪斜。
- 人物动作自然，一眼能理解为“正确理货动作”。
- 与 `MS02 master` 在环境、机位、灯光上保持同一体系。
- 人物应明显为东亚面孔，且整体更像中国学校实训角色，不像海外零售广告模特。
- 货架商品包装应尽量无文字或低文字；若有文字，不应出现大面积无意义乱码。

失败信号：

- 商品是否正面朝外看不清。
- 人物遮挡太多，动作读不出来。
- 虽然整齐，但像陈列广告图，不像训练动作图。

### 3.3 `JDG-MS02-facing-wrong-v001`

用途：货架错误态 edit 验证。

通过标准：

- 保留正确态的大部分环境和机位，不像重新生成了另一张图。
- 只改动作和摆放结果：歪斜、错向、不对齐。
- 错误一眼可见，但不是灾难性混乱。
- 还能和正确态形成清晰对照组。
- 人物 ethnicity 与整体环境语境必须延续正确态，不得漂移。
- 货架商品包装应延续正确态的低文字体系，不能因为 edit 变成大量乱码货架。

失败信号：

- 整个场景换了、人物换了、灯光换了。
- 错误不够明确，看起来只是“另一个正常摆法”。
- 错误过头，变成翻倒、掉满地、戏剧事故，不适合常规判断题。

### 3.4 `JDG-MS04-safety-risk-master-v001`

用途：安全母版。

通过标准：

- 同一画面内能容纳湿滑、电源、清洁用品、安全工具台等要素，但不拥挤。
- 画面是“教学演示区”，不是事故现场。
- 可继续扩出多个安全判断题，不需要重搭场景。
- 与 `MS02` 有明显区分，但仍属于同一套资产风格。
- 人物与空间更像中国大陆学校实训安全角，而不是海外商超后场。

失败信号：

- 危险元素堆得太满，变成混乱杂物间。
- 画面过于惊险、夸张、压迫，不适合日常测评。
- 安全元素过弱，后续不好做细分题。

### 3.5 `DRG-BG01-shelf-alignment-board-v001`

用途：拖拽货架底图。

通过标准：

- 落点区域清晰，但不是靠文字说明。
- 货架格位边界够清楚，后续叠加 draggable 商品不会糊成一团。
- 背景干净，适合界面叠题干、按钮、页码。
- 保持真实货架感，不像纯 UI 线框图。
- 不带明显海外卖场视觉符号。

失败信号：

- 落点区域过弱，看不出拖到哪里。
- 背景太满、商品太多，叠 UI 后会很脏。
- 透视太强，拖拽定位会不好用。

### 3.6 `DRG-OBJ02-goods-facing-pack-v001`

用途：拖拽物商品素材包。

通过标准：

- 每个商品轮廓清楚，缩小后仍能分辨方向和正反面。
- 商品之间属于同一视觉体系，不像东拼西凑的 6 张图。
- 正面朝向可读，适合做“正面朝外”题。
- 白底干净，无强反光、无品牌风险、无乱码标签。
- 包装气质中性，可用于中国大陆学校软件，不带明显海外品牌感。

失败信号：

- 商品轮廓太像，学生难以区分。
- 正反面不明显，无法支持“朝外”判断。
- 包装表面出现大量乱码、假 Logo、花哨图案。

## 4. 建议打分方式

每个 job 按 4 项打分，每项 `0 / 1 / 2`：

1. 风格一致性
2. 题意可读性
3. 后续复用性
4. 画面干净程度

判定规则：

- 单张总分 `7-8`：通过
- 单张总分 `5-6`：可保留，但建议改 prompt 后重跑
- 单张总分 `0-4`：不通过，必须重跑

整批通过规则：

- 6 张里至少 5 张通过
- 且 `JDG-MS02-facing-wrong-v001` 必须通过
- 且 `DRG-BG01-shelf-alignment-board-v001` 必须通过
- 且 `DRG-OBJ02-goods-facing-pack-v001` 必须通过

原因：

- `JDG-MS02-facing-wrong-v001` 代表 edit 链路是否成立
- `DRG-BG01` 代表拖拽底图是否成立
- `DRG-OBJ02` 代表拖拽物素材体系是否成立

## 5. 不通过后的处理动作

### 场景母版不通过

优先调这些参数：

- 收紧环境描述，减少背景噪音
- 强化“training / assessment / instructional realism”
- 固定机位表达：`eye-level 28 mm lens feel`
- 增加 “no commercial advertising / no dramatic cinema”

### 错误态 edit 不通过

优先调这些参数：

- 更强地写 `preserve original camera angle / preserve layout / preserve lighting`
- 把错误限定为单一错误，不要一次改太多
- 明确写 `paired vocational training comparison image`

### 拖拽底图不通过

优先调这些参数：

- 强化 `front-facing composition`
- 强化 `minimal perspective distortion`
- 强化 `clear landing zones`
- 减少背景中的真实商品和杂物

### 拖拽物不通过

优先调这些参数：

- 强化 `clear silhouette`
- 强化 `consistent scale`
- 强化 `easy to read at drag-card size`
- 去掉花哨包装和强反光
