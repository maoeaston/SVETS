实际审核请使用 HTML 入口。本节只说明 HTML 中的字段含义，不应直接编辑本 Markdown。

线上单选题需要确认题干、选项、候选答案和素材裁决。素材裁决只能选一项：

- `TEXT_ONLY_APPROVED`：不依赖图片也能准确作答，允许纯文本施测。
- `ASSET_REQUIRED`：缺少图片或其他素材会影响理解、区分或作答，需写明素材要求。
- `RETURN_FOR_REVISION`：题干、选项、答案或职业口径需要修改。
- `REJECTED`：题目不适合进入本次 Pilot，应在新的 strategy version 中换题。

- “审核依据”应写职业规范、门店作业规则、培训口径或可核查的专业判断。
- 如改答案，必须写新答案和原因。

- 陈晓青签署的是内容与职教结论，不代替技术、安全和真实 Electron 见证。
