## 1. 本轮处理原则

### 1.1 版本与 hash

1. 7 道在线题改变了题干、选项、答案、素材条件或安全属性，必须生成新题目版本和新 `candidate_record_hash`，不得覆盖已审核候选。

3. 6 道离线实操题的数据合同已经通过，本轮只修渲染器；题目版本和 `candidate_record_hash` 保持不变。
4. 新 hash 必须由工程现有规范化序列化与 hash 计算程序生成，本文件不手工伪造 hash。

### 1.2 安全优先

1. 刀具、水渍、松动货架、碎玻璃，以及6道离线实操题均按安全敏感题处理。
2. 安全停止条件优先于普通评分；触发停止条件时不得继续按0/1/2分完成普通结算。
3. 补货速度只能在安全、FIFO/FEFO、归区和陈列质量均达标后用于效率观察，不得用速度覆盖安全或质量结果。

### 1.3 FIFO/FEFO与固定日期

1. 食品先核对是否可售和到期日，较早到期批次放在顾客先拿取的位置；同等效期再按先入先出处理。
2. 项目固定模拟工作日为 **2026-09-10**。
3. 原 `M2_SC_005_V2` 的两个日期在固定模拟工作日已经失效，因此新版本必须使用2026-09-10之后的两个可售到期日。

### 最终题目

**题干：**

使用安全开箱刀拆纸箱时，最优先要避免的是什么？

| 选项 | 内容 |
|---|---|
| A | 刀刃伤到自己或旁边的人 |
| B | 下刀太深划伤箱内商品 |
| C | 拆箱速度较慢影响补货进度 |

- 正确答案：`A`
- 唯一最佳答案：是

### 审核依据

人员防割伤必须高于保护商品和追求速度。实际操作还应同时使用合格安全开箱刀、最小出刃量、刀刃远离身体、非持刀手离开刀路；刀具松动、破损或无法回缩时立即停用。

### 素材条件

- 画面不得显示：朝身体切割、手压在切割线上、刀刃过度伸出、儿童接触刀具。
- 素材不满足以上条件时不得上线。

### 安全停止条件

发现刀具破损/松动、刀刃无法回缩、受试者朝身体或他人方向切割、非持刀手进入刀路时立即停止。

### 最终题目

**题干：**

模拟工作日是2026年09月10日。同款商品有两个仍可正常销售的批次：批次A标注“保质期至2026年09月25日”，批次B标注“保质期至2026年10月10日”。上架时应怎样摆放？

| 选项 | 内容 |
|---|---|
| A | 批次A放在顾客先拿取的位置，批次B放在后面 |
| B | 批次B放在顾客先拿取的位置，批次A放在后面 |
| C | 两个批次混在一起，不核对到期日 |

- 正确答案：`A`
- 唯一最佳答案：是

### 审核依据

在两个批次均处于可售状态的前提下，应让较早到期的批次先被取用，即旧/早到期批次前移，新/晚到期批次后置。若发现任一商品已经过期，应退出正常上架流程并按隔离、报告和报损制度处理。

### 素材条件

- 素材结论：`ASSET_REQUIRED`
- 画面同时显示模拟工作日和两件同款商品的“保质期至”标签。
- 日期文字必须用程序化叠加生成，不允许依赖AI直接绘制日期。
- 两个批次必须外观相同、日期清楚、均无“过期/报损”标记。
- 正确位置必须是顾客正常取货方向的前排，不使用含糊的上下或左右代替前后关系。

### 安全停止条件

模拟工作日与题干不一致、任一日期标签模糊、或任一批次在模拟工作日已过期时停止施测并更换候选数据/素材。

### 最终题目

**题干：**

发现货架旁地面有水渍，暂时不能马上清除，正确的完整做法是？

| 选项 | 内容 |
|---|---|
| A | 先守护并隔离水渍区域，阻止人员进入；再设置警示并通知清洁，确认地面干燥后复检撤除隔离 |
| B | 放一块“小心地滑”警示牌后离开，等清洁人员自己发现 |
| C | 自己绕开水渍继续理货，不处理也不报告 |

- 正确答案：`A`
- 唯一最佳答案：是

### 审核依据

警示牌只能提示，不能代替守护、疏离和隔离。完整流程为：发现危险 → 立即阻止人员进入 → 设置警示/隔离 → 通知处理 → 保持控制 → 确认清洁干燥 → 复检后撤除隔离。

### 素材条件

- 素材结论：`ASSET_REQUIRED`
- 正确图必须显示工作人员在水渍外侧守护、顾客被引导绕行、警示牌和隔离带/围挡同时存在。
- 不得只画一个警示牌后工作人员离开的场景作为正确答案。
- 水渍位置与人物行走动线必须清楚，避免答案依赖猜测。

### 安全停止条件

危险区域无法隔离、有人即将进入湿滑区、或清洁后仍未干燥时不得撤除警示和隔离。

## 2.4 M5_SC_002_V2 — 松动货架的疏离与封控

### 版本信息

- 新题号：`M5_SC_002_V2`
- 上一题号：`M5_SC_002`
- `question_version`：2
- 题型：`SINGLE_CHOICE`
- 目标能力：`SAFETY_OPERATION`
- `safety_sensitive`：`true`
- 建议 `review_level`：`safety_critical`

### 最终题目

**题干：**

发现货架支架松动，货架可能倒塌，正确的完整做法是？

| 选项 | 内容 |
|---|---|
| A | 立即停止作业，疏离周围人员并封控危险区域，禁止自行扶正或取货，通知负责人处理 |
| B | 自己停止理货并通知负责人，但不阻止顾客进入该区域 |
| C | 先把货架上的商品取下来，再找东西临时支撑货架 |

- 正确答案：`A`
- 唯一最佳答案：是

### 审核依据

只停止本人作业不能控制倒塌范围内的顾客和同事风险。无授权人员不得靠近、卸货、扶正或临时支撑，应先疏离、封控，再通知有权限人员处置。

### 素材条件

- 素材结论：`ASSET_REQUIRED`
- 正确画面显示：人员在安全距离外封控通道、引导顾客绕行、通知负责人。
- 货架仅表现“支架松动/明显倾斜风险”，不得制作真实倒塌或让受试者接近危险设备。
- 错误画面可显示试图取货或临时支撑，但不得呈现可模仿的详细危险动作教程。

### 安全停止条件

真实货架存在晃动或倾斜时不得用于施测；任何人试图进入危险区、扶正货架或取下商品时立即停止。

独自工作时发现玻璃瓶打碎在顾客通道上，正确的完整做法是？

| 选项 | 内容 |
|---|---|
| A | 先守护并封控区域、通知支援；按要求佩戴防护，用扫帚簸箕或夹具清理，放入防穿刺容器，检查无残片和泄漏后再解封 |

- 素材结论：`ASSET_REQUIRED`
- 使用仿真透明塑料碎片表现碎玻璃，不使用真实碎玻璃拍摄训练场景。
- 正确图必须出现：封控、扫帚簸箕/夹具、防穿刺硬质容器、防护用品和清场复检。

### 安全停止条件

施测不得使用真实玻璃；受试者徒手接触仿真碎片、进入未封控区域，或现场出现真实破碎/泄漏时立即停止。

## 5. 完成定义

只有同时满足以下条件，13道题才可从退回状态进入下一轮激活审查：

1. 7道在线题生成新候选记录、新版本和新hash，素材满足本文件的上线条件。
2. 7道在线题重新完成内容、安全与技术复审，不能沿用旧候选结论自动通过。
3. 6道离线题渲染自动化测试通过，且内容记录与原hash未被意外修改。
4. 6道离线题完成真实 Electron 见证，题干、工具、锚点、停止条件和权限隔离全部通过。
5. 安全敏感题的停止条件已接入现有安全事件与红线终止流程。
