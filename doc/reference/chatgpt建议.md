不是把298题重新扩充成一个混合题库，而是把它作为“核心测评母题库”，在其基础上有计划地扩展训练变式题。这样既保留正式测评的精炼性，也满足特殊需要青少年需要反复练习、跨材料泛化和逐步撤除提示的教学需求。

建议采用下面的结构：

## 一、298题作为核心测评母题

这298题主要承担三项功能：

* 明确每个岗位构念和标准作业规则；
* 提供正式测评候选题；
* 作为训练变式题的“母题”和质量基准。

核心题不宜频繁修改，也不应因为增加训练题而失去原有编号、构念和评分定义。后期新增的相似题，应当与母题建立明确映射关系。

例如：

> 母题M1-008：发现商品和价签价格不一致时如何处理。

可以扩展训练变式：

* T-M1-008-01：饼干价签8元，系统10元；
* T-M1-008-02：饮料价签对应了另一种规格；
* T-M1-008-03：促销结束后旧价签未撤；
* T-M1-008-04：同品牌不同容量商品价签放反；
* T-M1-008-05：实物货架中找出两个错价签并处理。

这些题表面相似，但可以逐步增加商品变化、视觉复杂度和异常类型。

## 二、新增题应进入独立的训练题库

不建议把新增训练题直接计入298题的正式测评池。应至少分成：

| 题库     | 主要用途                |
| ------ | ------------------- |
| 核心测评题库 | 阶段评估、结业组卷、能力比较      |
| 训练变式题库 | 教学、反复练习、错题强化        |
| 泛化训练题库 | 换商品、换环境、换呈现方式后的迁移练习 |
| 固定结业卷库 | A/B/C等相对稳定的结业试卷     |

这样可以避免训练时反复出现的题目，又被原样抽到正式考试中，导致结业分数主要反映记忆，而不是独立掌握和迁移。

## 三、相似题不能只是机械换词

后期补充训练题时，可以保留相同构念，但每道变式题应至少改变一个有教学意义的变量。

### 1. 更换材料

例如同样训练“重物放下层”，可以使用：

* 大桶水；
* 大桶洗衣液；
* 整箱饮料；
* 袋装大米；
* 大瓶食用油。

材料变化有助于检验学生是否掌握“重量和安全”原则，而不是只记住“大桶水放下层”。

### 2. 更换异常形式

例如价签问题可以分别训练：

* 价签缺失；
* 价签模糊；
* 价签歪斜；
* 商品与价签错位；
* 价格不一致；
* 规格不一致；
* 促销标签过期。

这些内容属于同一大维度，但处理权限和流程可能不同，具有必要的训练价值。

### 3. 更换呈现方式

同一构念可以设计为：

* 文字选择；
* 实拍图片判断；
* 短视频判断；
* 拖拽分类；
* 实物操作；
* 模拟工作任务。

训练时由简单、明确的呈现逐步过渡到真实复杂场景。

### 4. 调整提示强度

可以形成同一任务的提示梯度：

1. 答案示范；
2. 图片提示；
3. 流程卡提示；
4. 首步提示；
5. 口头提醒；
6. 完全独立完成。

这类变式对职业康复尤其重要，因为它能够测出学生需要哪一种支持，以及支持是否能够逐步撤除。

### 5. 增加干扰和迁移

后期训练可以逐步增加：

* 同类干扰商品；
* 不相关商品；
* 背景噪声；
* 中途打断；
* 任务切换；
* 不同货架布局；
* 不同标签版式；
* 不同工作指令表达。

但这些干扰应分层加入，不能一开始就同时出现多个困难因素。

## 四、建议为每道母题建立“变式族”

每道适合扩展的核心题，可以建立一个题目家族：

```text
母题：M2-006
构念：先进先出——新旧货复位
规则：旧货在前，新货在后
训练变式：
- V1 单一商品、两批次、日期颜色明显
- V2 单一商品、两批次、真实日期标签
- V3 三批次混合
- V4 多种商品中只处理指定商品
- V5 实物补货操作
- V6 中途被打断后继续完成
泛化题：
- 办公耗材按入库日期先后使用
- 餐饮原料按有效期先后摆放
```

这样可以明确哪些题只是相同规则的训练变式，哪些题已经扩展到了跨岗位迁移。

## 五、训练题扩充应遵守四项控制

### 1. 不污染结业测评

进入结业卷的题目，不能与训练题完全相同。至少应更换：

* 商品或材料；
* 图片和版式；
* 数字；
* 货架布局；
* 情境背景。

但目标构念和难度要保持一致。

### 2. 不让某些构念过度膨胀

容易生成题目的构念，例如分类、摆放和判断，可能快速积累大量题目；较难设计的构念，例如中断恢复、安全应对和工作节奏，却题量不足。

因此扩题应依据“构念覆盖表”，而不是哪里容易出题就往哪里增加。

### 3. 训练题也要经过规则审查

即使不用于正式考试，也不能出现：

* 与企业SOP冲突；
* 多个合理答案；
* 商品安全边界不清；
* 隐性社交推断；
* 明显答案措辞线索；
* 不符合真实岗位权限的处理方式。

否则错误规则会在训练阶段被反复强化。

### 4. 训练记录与测评结果分开

训练系统应记录：

* 练习次数；
* 首次正确率；
* 提示类型；
* 提示撤除情况；
* 错误类型；
* 跨材料泛化；
* 延迟保持。

但这些数据不能直接等同于结业测评成绩。训练表现反映学习过程，正式测评反映在规定条件下的独立表现。

## 六、建议的扩充规模

298题可以先保持为正式测评候选母题库。训练变式题可分阶段扩充，不必一次性完成。

比较稳妥的第一阶段是：

* 每道核心构念选1—3道母题；
* 每道母题增加3—5个训练变式；
* 对安全、临期、价签、FIFO、盘点等重点构念增加更多边界变式；
* 实物题优先增加材料和环境变化，而不是简单复制文字题。

最终训练题库达到600—1000题并不一定过多，只要它们是按构念、难度、提示和用途组织的，并且不会全部用于同一次正式测评。

## 七、系统中应增加的题目标签

后期扩题时，建议每道题至少包含：

```yaml
item_id:
parent_item_id:
item_usage: training | assessment_candidate | graduation_form
module:
construct:
work_rule:
difficulty:
presentation_type:
material_variant:
context_variant:
support_level:
generalization_level:
safety_critical:
exposure_count:
status:
version:
```

其中：

* `parent_item_id`：指向298题中的母题；
* `item_usage`：明确是训练题还是测评题；
* `support_level`：标记提示强度；
* `generalization_level`：标记是否只是换材料，还是跨情境迁移；
* `exposure_count`：记录受测者是否已经见过；
* `safety_critical`：标记安全关键题。

## 结论

可以在298题基础上继续补充大量具有训练价值的相似题，而且应当这样做。但需要坚持：

> 298题负责定义核心构念和正式测评标准；新增相似题负责教学重复、难度分层和迁移训练；固定结业卷负责独立考核。
