## ⚠️ 特殊设计约束（务必阅读）

本产品面向**轻中度自闭症/智力障碍青少年**，所有视觉素材必须遵循以下红线：

| # | 约束 | 原因 |
|---|:---|:---|
| 1 | **禁止使用红色系** (#FF0000, #F44336等) | 红色对感官敏感群体产生焦虑/攻击性关联 |
| 2 | **色彩柔和低饱和** | 避免过度视觉刺激 |
| 3 | **图形简洁，无复杂背景** | 减少认知负荷，突出主体 |
| 4 | **每张图只表达一个概念** | 多信息并存会导致理解困难 |
| 5 | **人物表情正面/中性** | 避免夸张表情引发模仿或恐惧 |
| 6 | **风格高度统一** | 这些学生对不一致性非常敏感 |
| 7 | **最小可辨识尺寸 ≥ 80×80px** | 触控操作精度有限 |

## APIMart GPT-Image-2 平台参数说明

### 平台支持的核心参数

| 参数 | 可选值 | 说明 |
|:---|:---|:---|
| `model` | `gpt-image-1` | 模型固定 |
| `size` | 支持比例关键词或直接像素值 | 详见下方比例映射表 |
| `quality` | `low` / `medium` / `high` | 图片质量等级 |
| `background` | `transparent` / `opaque` / `auto` | 背景透明度 |
| `output_format` | `png` / `webp` / `jpeg` | 输出格式 |
| `n` | 1-4 | 单次生成图片数 |

### 4K 尺寸/比例映射表 [^1]

APIMart 的 GPT-Image-2 支持 **15 种比例**，可通过比例关键词或直接像素值传入 `size` 参数：

| 比例 | 像素尺寸 (size可直传) | 适用场景 |
|:---|:---|:---|
| `1:1` | `1024x1024` / `4096x4096`(4K) | 头像、商品图、图标 |
| `3:2` | `1536x1024` | 横向中等比例 |
| `2:3` | `1024x1536` | 纵向中等比例 |
| `16:9` | `1792x1024` / `4096x2304`(4K) | 宽屏横幅、启动画面 |
| `9:16` | `1024x1792` / `2304x4096`(4K) | 纵向全屏 |
| `4:3` | `1536x1152` | 接近传统屏幕比例 |
| `3:4` | `1152x1536` | 纵向传统比例 |
| `2:1` | `2048x1024` | 超宽横幅 |
| `1:2` | `1024x2048` | 超长纵向 |
| `5:4` | `1280x1024` | 接近正方形的横向 |
| `4:5` | `1024x1280` | 接近正方形的纵向 |
| `7:4` | `1792x1024` | 电影感横向 |
| `4:7` | `1024x1792` | 电影感纵向 |
| `3:1` | `3072x1024` | 极宽横幅 |
| `1:3` | `1024x3072` | 极长纵向 |

### 关于透明背景的重要说明

根据搜索信息 [^2]，**原版 OpenAI gpt-image-2 不支持透明背景**。但 APIMart 平台可能在其封装层提供了 `background: transparent` 参数支持。建议：
- 优先尝试 `background: "transparent"` + `output_format: "png"`
- 如果平台实际不支持透明，则在 prompt 中写 `"on a solid pure white (#FFFFFF) background"`，生成后用工具去底

## 八、给 Skills 的快速调用参考

Skills 在调用时，每张图只需要以下 4 个核心字段：

```
{
  "prompt": "...(上面对应的完整prompt文本)...",
  "size": "1024x1024",          // 或 "1536x1024" / "1792x1024"
  "quality": "high",            // 固定 high
  "background": "transparent"   // 或 "opaque"
}
```

如果你的 Skills 还需要 `output_format`，统一填 `"png"`。

如果平台实际不支持 `transparent` 背景（生成出来还是有背景），你可以在 prompt 末尾追加一句：
```
The subject should be placed on a solid pure white (#FFFFFF) background with absolutely no shadows, gradients, or textures — just flat white for easy background removal.
```
然后后处理去白底。

## 九、后处理说明

| 操作 | 说明 |
|:---|:---|
| 缩放 | 所有 1024×1024 生成的图，缩放到应用目标尺寸时使用 Lanczos/双三次算法 |
| 裁切 | 货架背景图（1536×1024）裁切到 1200×600/800 时，居中裁切 |
| 启动画面 | 1792×1024 生成后，等比拉伸到 1920×1080（或居中 + 边缘延伸填充） |
| 透明度检查 | 确认 PNG 文件的 alpha 通道正确，无白色光晕 |
| 色彩审计 | 用取色器确认无 #FF0000 系色值 |
| 文件命名 | 按素材ID命名，如 `fruit_apple_01.png` |
