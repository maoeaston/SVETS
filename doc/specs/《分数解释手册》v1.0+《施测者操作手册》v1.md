# 交付文件一：《分数解释手册》v1.0

**适用工具**：专业岗位能力测评题库 改进版 v3.0（六模块，约298题/项）
**适用对象**：特殊需要青少年（ASD、ADHD、智力障碍等）实习安置评估
**使用者资质**：本手册仅供完成本工具施测培训的职业康复顾问、特教评估人员、心理评估人员使用

---

## 第一章 总则

### 1.1 工具定位

本工具是**岗位安置支持工具**，不是能力等级鉴定工具。其输出用于回答四个问题：

1. 该学生适合安置到哪类岗位环境（门店理货／仓储分拣／文职整理）？
2. 安置后需要配置哪些支持与辅具？
3. 哪些岗位职责应纳入、哪些应剥离？
4. 岗前培训还需补强哪些内容？

**本工具的任何分数不得用于**：入学/录用的一票否决、与其他学生横向排名、给学生或家长贴"能力等级"标签。

### 1.2 三条根本解释原则

> **原则一：知行分离原则。** 纸面分数（选择/判断/拖拽）反映"知不知道"，实物分数反映"做不做得出来"。二者不可互相替代，且对本群体二者常显著分离。**任何向雇主出具的安置建议，只能以实物操作分为依据。**

> **原则二：非对称解释原则。** 纸面题低分有预警意义（提示知识缺口或加工障碍，需追查原因），纸面题高分**不构成**能力证据（可能来自应答策略残留或规则背诵）。低分要认真对待，高分要保持怀疑。

> **原则三：分数即处方原则。** 本工具约三分之一的编码项（支架分差、中断恢复、辅助工具使用、追问行为等）不是"能力分"，而是**支持需求信号**。这些项目上的"低表现"应转译为支持配置，而非能力缺陷结论。

### 1.3 施测前提

全部题目答案以《标准作业规则表》R1–R14为唯一标准。**施测前必须确认受测者已完成R1–R14的岗前教学并留存记录**（确认单见操作手册附录A）。未完成教学即施测的，规则应用类题目（如模块五题9、题10）分数无效。

## 第二章 分数结构：五类分数的定义与计算

本工具输出**五类分数，分开报告，永远不合成单一总分**。

### 2.1 第Ⅰ类：岗位操作分（Operational Score）

**来源**：全部实物操作题（六模块共91项）
**计分**：按各题5分制计分规则；按模块分别汇总为百分比得分
**性质**：唯一可对外（雇主、安置机构）出具的能力证据
**细分报告单元**：

| 单元 | 组成题目 | 对应岗位证据 |
|---|---|---|
| 排面维护 | M1题33–47 | 超市理货 |
| 收货补货 | M2题27–41 | 超市理货/便利店 |
| 效期与分拣 | M3题43–58 | 理货/分拣（含效期管理职责专项） |
| 收纳盘点-门店版 | M4题28–42 | 库房/仓储 |
| 收纳盘点-文职版 | M4题43–48 | 办公室文档整理 |
| 应急执行 | M5题39–55 | 各岗位准入安全项 |
| 识别分类 | M6题34–48 | 理货/分拣通用 |

### 2.2 第Ⅱ类：规则知识分（Knowledge Score）

**来源**：全部选择题（96题）+判断题（68题）
**计分**：按模块汇总正确率
**性质**：仅供内部使用的筛查与教学诊断分数，**不写入对外报告的能力结论部分**
**解释阈值**（试测校准前的暂行值，校准后以实证值替换）：

- 模块正确率 <60%：红色预警，暂缓该模块对应岗位职责的安置，先补教学
- 60%–80%：黄色，可安置但对应职责需加强督导期
- >80%：仅表示"知识层面无明显缺口"，**不得**表述为"能力达标"

### 2.3 第Ⅲ类：流程支持需求指标（Scaffolding Index）

**来源**：全部拖拽流程题的**支架版与无支架版分差**（各模块支架配对题）
**计算**：支架版得分率 − 无支架版得分率
**解释**：

| 分差 | 解释 | 处方 |
|---|---|---|
| ≤10% | 流程可自主重建 | 无需流程卡 |
| 10%–30% | 有提示即可执行 | 配发任务流程卡（贴工牌背面/操作台） |
| >30% | 依赖外部序列支持 | 流程卡+分步口头指令+首月逐步撤除计划 |

**禁止**：将无支架版低分单独解释为"不会该项工作"——须先看支架版，支架版高分者的问题是记忆负荷而非知识。

### 2.4 第Ⅳ类：注意与执行观察指标（Attention & EF Index）

**来源**（均为过程编码，非对错计分）：

| 指标 | 采集点 | 解释方向 |
|---|---|---|
| 判断题前后半程正确率差 | 各模块判断题分节数据 | 差值>15%提示注意衰减显著→短时段排班、任务切换设计 |
| 实物题完成时长 | 全部计时题 | 与试测常模对照；仅慢不错→允许安置但与雇主约定效率预期；快且错→冲动风格，加自查步骤 |
| 中断恢复编码 | M1题42、M2题41、M4题41/48 | "接续不重做"=可耐受打断环境；"需重做"→单任务保护性排班 |
| 警觉衰减点 | M3题58（20件隐性问题盘） | 衰减点<10件→检查类任务单次时长限制在对应件数内 |
| 干扰版-安静版分差 | M1题45双版本 | 分差大→申请低感官负荷工位/错峰班次 |

### 2.5 第Ⅴ类：社交应对与元认知编码（Social & Metacognitive Codes）

**来源**（均单独编码，不计入任何能力分）：

| 编码项 | 采集点 | 解释 |
|---|---|---|
| 求助脚本执行 | M5题54（三步逐级计分：话术1/找人2/交接2） | 5分=脚本完整；≤3分→脚本演练强化，安置初期配"求助对象"明确指定 |
| 自发应对 | M1题48（碰倒水瓶嵌入观察） | 记录反应类型，不评优劣；"无反应"者安置说明中注明需明确职责边界告知 |
| 模糊指令反应 | M5题55（"你先弄那个吧"） | 追问澄清=积极预测指标，写入优势项；猜测执行=风险项→指令下达规范写入雇主对接单 |
| "不清楚"选项选择率 | M3题6/7/9/14 | 高选择率+对应实物题低分=元认知诚实，可教性好；从不选+错误率高=过度自信风险，加复核机制 |
| 辅助工具主动使用 | M3题47、M2题31 | 主动用=辅具接纳度好，直接配发；不用且算错→辅具引入训练 |
| ASD社交簇失分 | M5第二节矩阵题 | **单列报告，永不并入岗位能力结论**（见第五章双轨规则） |

## 第三章 模块级解读要点

### 3.1 模块一（货架整理+价签核对）
- 题14（综合纠错）与实物题45（找3处问题）构成知行配对：纸面对+实物错→执行转化训练；纸面错+实物对→阅读/图片理解障碍，复查其全部纸面分的效度。
- 实物题45双版本分差是**环境敏感度**的首要证据，优先于任何问卷式感官评估写入安置建议。

### 3.2 模块二（拆箱补货+FIFO）
- FIFO四级阶梯（题2→5→6→实物29/36/41）逐级看断点：断在题2=概念未建立（回炉教学）；断在题6=操作逻辑未通（现场示范教学）；纸面全通、实物断=典型知行分离（现场带教+流程卡）。
- 题35（预埋差错检出）失分≠不会数数，须区分"数错"与"未比对"——查过程记录中是否有逐行比对行为。

### 3.3 模块三（临期破损分拣）
- **日期计算链（题5–10）是效期管理职责的准入门槛**：题5–7通过→可承担单品效期检查；题9–10通过→可承担批量巡检；均不通过→安置时剥离效期职责（纯摆放岗），或配"临期对照卡+计算器"后复测。
- 方向配对题（6↔7、11↔18、39↔40）：若同方向全对、反方向全错→应答定势，该区段知识分作废，仅以实物分为准。

### 3.4 模块四（库房收纳+盘点）
- **门店版−文职版分差是安置环境决策的核心数据**：文职版显著更优（分差>15%）且第Ⅳ类指标显示环境敏感→优先推荐文档整理类岗位；两版相当→按兴趣与通勤等现实因素决策。
- 题31（按单拣货）单题得分直接写入仓储分拣岗推荐意见。

### 3.5 模块五（突发应对）
- 纸面分只回答"脚本是否具备"。安置结论必须同时引用：题54（诱发求助）+题48/55（嵌入观察）+实物流程题。四者一致方可写"具备基本应急应对"；纸面高、诱发低→报告表述为"知识具备，现场启动需支持"，配应急卡与首月督导。
- 陷阱题14/17/19专项检查：三题全错且其余全对→"一律求助"过度泛化，需教"职权内直接处理"的边界；反之全对→泛化良好，写入优势。

### 3.6 模块六（商品识别分类）
- A组基础题（1–6）任何失分→立即启动追查（是知识缺口还是图片/表达通道问题），并考虑"图卡匹配式"归位支持（货架贴样品图）。
- B组近邻题+实物题46三轮递进：通过轮次决定归位职责精度——仅过远距→大类归位职责；过近邻→可承担精细归位与纠错巡架。

## 第五章 双轨解释规则（ASD/ADHD专项）

### 5.1 ASD受测者
1. 模块五第二节（社交矩阵）失分**一律计入第Ⅴ类编码**，报告中表述为"社交推断支持需求：××情境需预置脚本"，禁止表述为"应变能力不足"。
2. 若纸面题出现对"荒谬选项"的认真选择（如选择字面可行的极端选项），标记该题并访谈确认是否字面化解读，确认后该题不计分。
3. 追问行为（"轻微是多轻？"）记为**优势项**。
4. 规则应用题失分先核查该规则教学记录，教学缺失的失分归因于教学而非学生。

### 5.2 ADHD受测者
1. 判断题前后半程差>15%时，后半程失分降权处理（以前半程正确率为准报告知识分）。
2. 反应时短于常模1.5个标准差且错误率高→全部纸面分标注"冲动应答风险"，以实物分为准。
3. 中断恢复与警觉衰减点数据**必须**写入雇主对接单的排班建议。

## 第六章 报告撰写规范

**对外报告（给雇主/安置机构）只含**：Ⅰ类分数+安置建议+支持配置清单+优势项。
**内部报告（教学团队）另含**：Ⅱ–Ⅴ类全部数据+教学补强清单。
**报告禁语清单**：禁止"智力/能力低下""不适合工作""通过/不通过"等结论式表述；一律使用"在××支持下可完成××""××职责建议剥离/后置"。

**报告模板（对外版）骨架**：
1. 评估工具与日期 2. 岗位操作分分单元呈现（雷达图） 3. 推荐安置方向及依据（引用具体实物题表现） 4. 支持配置清单（对照第四章矩阵） 5. 优势项 6. 建议复评时间

## 第四章 标准化指导语

> 以下指导语**逐字宣读**，可放慢、可重复，不可改写。全部指导语已做简明化处理（短句、无从句、无习语）。

**总开场**：
"今天我们做一些和超市工作有关的任务。有的题在平板上做，有的题是动手做。不会做没有关系。如果题目没看懂，你可以问我'这题是什么意思'，我会再读一遍。做累了可以说'我要休息'。准备好了吗？"

**选择题**：
"看题目和三张图。选一个你认为正确的，点它。每题只选一个。"

**判断题（视频式）**：
"看这段视频。视频里的员工这样做，是对的还是错的？对，点✓。错，点✗。"

**拖拽排序**：
"这里有几个步骤卡片，顺序是乱的。把它们按先做到后做的顺序排好。"
（支架版加读："第一步已经放好了，你排后面的。"）

**拖拽分类**：
"把每张图片拖到它应该在的区域里。"

**实物题**：按各题题卡宣读任务指导语（附录C逐题指导语卡），宣读后说："开始吧。"并启动计时。

**"不清楚"选项说明（模块三首次出现前宣读一次）**：
"有的题目有一个选项是'不确定，需要查询'。如果你算不出来、真的不确定，选它是可以的，这不算错。"

## 第六章 实物题专项操作规程

### 6.1 计时规范
指导语读完、说"开始吧"的同时启动计时；受测者宣布完成或明显停手10秒即停表。中途提问不停表（提问时间另记）。

### 6.2 中断版操作（M1题42、M2题41、M4题41/48）
- 中断时点：任务进行至约50%时
- 标准中断语（逐字）："**不好意思打断一下——你昨天晚饭吃了什么？**"（等待回答，最长20秒）"谢谢，你继续。"
- 编码：`A接续不重做 / B部分重做 / C完全重做 / D无法恢复需提示`
- 禁止：中断后给任何进度提示（"你刚才摆到第6件了"）

### 6.3 干扰版操作（M1题45）
- 背景音：标准门店环境音频（随工具包提供，音量55–60dB，测前用手机分贝计校准）
- 安静版与干扰版间隔≥1天，顺序在被试间平衡

### 6.4 预埋差错题（M2题35、M4题35/46）
- 差错版本单据由记录员按附录B当场取用，主试不知差错位置（防无意暗示）
- 编码：`检出并指出 / 检出未报告 / 未检出`——"检出未报告"单独记录，提示上报环节需专项训练

### 6.5 嵌入式观察三项（M1题48、M5题48预案、M5题55）
- **性质**：非预告。执行前须已获监护人知情同意书中"过程观察条款"授权
- M1题48（碰倒水瓶）标准动作：主试整理材料时以手肘带倒预置塑料水瓶（空瓶+瓶内少量蓝色示踪水），随即转身背对3秒。编码：`扶起/清理 / 口头提醒主试 / 注视无动作 / 未注意`
- M5题55（模糊指令）标准台词："（看手机）不好意思我接个电话——**你先弄那个吧。**"（手不指向任何物品，离开视线30秒）编码：`追问澄清 / 等待 / 猜测执行（记录执行内容）`
- **事后必须告知**："刚才那个是任务的一部分，你的反应很有价值，谢谢你。"并观察情绪反应，如有不安即启动安抚流程（第十章）

### 6.6 角色扮演规范（M5题52/54）
- 评估员台词**逐字**使用附录D脚本，禁止即兴、禁止方言、禁止反讽语气；语速中等，每句后停顿2秒
- M5题54标准台词："你好，请问这款奶粉，乳糖不耐受的人能喝吗？"（受测者任何回应后，若其执行找人步骤，扮演者原地等待；若其开始编造回答，任其说完，不打断，如实编码）

## 第七章 提示层级与允许/禁止行为

**允许（不影响计分）**：
- 重读题目/指导语（不限次数，记录次数）
- 回答"这题是什么意思"——仅可重读+同义替换单个生词，不得举例
- 中性回应受测者的完成宣告："好的，下一题。"

**分级提示（仅实物题，逐级记录，触发即在该题编码"提示级别"）**：
- L1 一般提示："再检查一遍。"
- L2 定向提示："看看这一层。"
- L3 示范提示：演示一件，受测者完成其余
- L3使用后该题得分上限降为3分并标注

**绝对禁止**：
- 对纸面题任何形式的选项提示、表情反馈、语气差异
- "你确定吗？"（该句对本群体构成强烈改答暗示）
- 催促（"快一点"）——限时题到时即停，不预警倒计时（M3题53类限时题除外：开始前告知"这个任务有3分钟时间"，允许放置可视沙漏）

## 第九章 特殊情况处理

| 情况 | 处理 |
|---|---|
| 拒答单题 | "可以跳过，我们做下一题。"记`跳过`，不追问原因 |
| 连续跳过≥5题 | 休息10分钟；恢复后仍拒→中止本场，记录中止点 |
| 情绪升级（哭泣、激越、自伤征兆） | 立即中止，启动该生个别化安抚预案（测前从档案调取），当日不再施测；数据保留至中止点，标注"情绪中止" |
| 对嵌入观察表现不安 | 执行6.5事后告知+安抚；如不安持续，该生后续场次取消全部嵌入项并在报告中注明 |
| 反复问"我做得对不对" | 统一回应："你做完所有题以后，老师会和你一起看。"（逐字，每次相同） |
| 设备故障 | 切换纸质备用版，标注题号（纸质版数据分析时单独标记） |
