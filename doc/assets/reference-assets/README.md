# 核心参考资产包 R1-R6

本目录存放 `visual-asset-master-plan.md` 定义的核心风格锚。参考资产本身也必须登记在
`asset-manifest.json`，完成技术门和视觉门审核后才能被正式生产素材引用。

目录约定：

- `ref_r1_character_sheet/`：理货员正面、45 度、侧面、全身和半身设定
- `ref_r2_vest_standard.png`：绿色工作马甲标准图
- `ref_r3_shelf_standard.png`：三层货架主场景标准图
- `ref_r4_product_masters/`：每个商品品类的已审核母版
- `ref_r5_lighting_camera.png`：光照、机位、色温和镜头距离参考板
- `ref_r6_icon_style_board.png`：图标风格九宫格
- `video-scene-anchors/`：A-F 六类判断题与 G 类训练示范的视频场景锚图；属于生产中间件，不计入 237 条运行时资产合同

目前六项均为 `planned`，本 README 不代表参考图已经生成或批准。
