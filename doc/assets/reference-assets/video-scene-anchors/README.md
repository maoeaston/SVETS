# 视频场景锚图

本目录存放 Seedance 生产用场景锚图，不计入应用运行时 237 项视觉资产。

至少需要：

- `template_a_shelf.png`：货架摆放场景
- `template_b_unpacking.png`：拆箱补货场景
- `template_c_expiry.png`：日期检查和临期处置场景
- `template_d_warehouse.png`：库房和收货场景
- `template_e_safety.png`：安全和应急场景
- `template_f_classification.png`：商品识别和分类场景
- `offline_demo.png`：线下操作示范场景

每张锚图应由已批准的 R1、R2、R3、R4、R5 参考资产组合，包含角色与环境，用于锁定人物、货架和道具的相对比例。

锚图是生产中间参考，不得直接作为题目素材引用。使用时应在对应生成批次 QA 记录中保存文件 SHA-256 和版本。
